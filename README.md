# Beatrixe

Windows downloads for Beatrixe, a local PDF and EPUB organizer.

Latest: [Beatrixe 0.1.5](https://github.com/AkkiBoi13/Beatrixe/releases/latest) fixes the browser companion: an honest connection status with versions, retries while Beatrixe is busy, site labels for subdomains and mirror downloads, and no 256-download limit. It also quiets the new-folder reminder when the folder list is full. See the [changelog](CHANGELOG.md) for every release.
