# Beatrixe

Windows downloads for Beatrixe, a local PDF and EPUB organizer.

Latest: [Beatrixe 0.1.6](https://github.com/AkkiBoi13/Beatrixe/releases/latest) fixes everything found in a full review of the app and the browser companion: Undo can be retried, startup recovery no longer strands moves, scans never offer existing folders for removal, personal documents are never sent to AI, and the folder editor renames only what you meant. See the [changelog](CHANGELOG.md) for every release.
